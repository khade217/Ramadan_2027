# 🌙 Ramadan 2027 — The Ethereal Manuscript ✨

Welcome to the **Ramadan 2027 (1448 AH)** tracker! This is a beautifully crafted, dark-mode web application designed with a premium emerald and gold aesthetic to help you track the holy month with elegance and ease. 🕌💚

🔗 **[Live Demo](https://khade217.github.io/Ramadan_2027/)** 💻

---

## 🌟 Features

This app is packed with features designed in a modern, scannable Bento-box layout:

* 🍱 **Bento-Style Countdown:** Never miss a second! Tracks Days, Hours, Minutes, and Seconds until the expected start on March 9, 2027.
* 🌑 **Signature Moon-Phase Tracker:** A gorgeous visual element mapping the transition from Sha'ban 1448 into the holy month of Ramadan.
* 📅 **Elegant Monthly Calendar:** A clean, custom grid layout for March 2027 highlighting key spiritual milestones.
* 🔔 **Key Spiritual Milestones:** Quick-glance cards marking **Ramadan Begins**, **Laylat al-Qadr** (The Night of Power), and **Eid al-Fitr**.
* 📱 **Mobile-First & Glassmorphic UI:** Smooth, fluid design featuring a glassmorphic sticky header, a bottom navigation bar, and a quick-access Floating Action Button (FAB).

---

## 🎨 Design & Aesthetic

The UI is built on a custom material-inspired color palette that channels peace, spirituality, and modern minimalism:
* **Deep Emeralds:** `#081612` (Background) & `#064e3b` (Primary Containers) 🌲
* **Soft Mint Highlights:** `#95d3ba` (Primary Text/Accents) 🌱
* **Warm Moonlit Gold:** `#e9c349` (Secondary Icons & Countdown) 🌙
* **Typography:** The structural elegance of *Noto Serif* paired with the clean readability of *Plus Jakarta Sans*.
